# Project Overview

This project explores survey data collected from data professionals across different countries and job roles using Power BI.

The dashboard was designed to transform raw survey data into meaningful insights related to:
- Salary trends
- Work-life balance
- Career satisfaction
- Programming language preferences
- Entry difficulty into the data field
- Demographic analysis

This project demonstrates skills in:
- Power BI Dashboard Development
- Data Cleaning
- Power Query Transformations
- Data Visualization
- Business Intelligence
- Data Normalization
- Insight Generation

---

# Business Understanding

The goal of this project was to analyze responses from data professionals to better understand trends within the data industry.

The dashboard focuses on answering questions such as:
- Which countries had the most survey participants?
- Which data roles reported the highest average salaries?
- Which programming languages were most preferred?
- How satisfied were professionals with salary and work-life balance?
- How difficult is it to break into the data industry?

This project also provided hands-on experience with data cleaning and dashboard creation using Power BI.

---

# Data Understanding

The dataset contains survey responses from professionals working in various data-related roles such as:
- Data Analysts
- Data Scientists
- Data Engineers
- Data Architects
- Database Developers

Key data fields included:
- Country
- Job Title
- Salary
- Favorite Programming Language
- Age
- Work-life Balance Rating
- Salary Satisfaction Rating
- Career Difficulty Rating

---

# Data Cleaning & Preparation

Before building the dashboard, the dataset required multiple cleaning and transformation steps using Power Query.

The preparation process included:
- Data normalization
- Converting string values into numeric data types
- Replacing incorrect or inconsistent values
- Separating columns to extract meaningful information
- Removing unnecessary data
- Preparing fields for visualization and analysis

These transformations helped improve data accuracy and dashboard performance.

# Key Insights

- Data Scientists earned the highest average salaries among surveyed roles.
- Python remained the most preferred programming language.
- Work-life balance satisfaction was stronger than salary satisfaction.
- Many respondents considered entering the data industry moderately difficult.
- Survey participation was concentrated in countries with strong technology sectors.
